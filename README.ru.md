Paperloom следит за папкой **входящих** (inbox). Для каждого файла, который ты
туда кидаешь, он читает содержимое, решает, к какой из **твоих** категорий он
относится, даёт аккуратное имя и перемещает в **архив** — аккуратное дерево папок
по темам.

```
   inbox/                          archive/
   ├── scan_20250612.pdf   ──▶     ├── 01 Налоги/
   ├── счёт.pdf                    ├── 02 Банк/2025-06-12 · Выписка.pdf
   └── паспорт.jpg                 ├── 05 Документы и личное/Паспорт.jpg
                                   ├── _Duplicates/     ← тот же контент, сохранён
                                   └── _Review/         ← «не уверен» — решаешь ты
```

**Никаких зависимостей** — только стандартная библиотека Python — и дружелюбный
мастер настройки. Нейросеть **опциональна и подключаемая**: можно гонять модель на
своём компьютере (приватно, бесплатно), взять API с оплатой за использование или
вообще обойтись без ИИ и сортировать по ключевым словам.

> 🧵 Paperloom — сестра [Threadloom](https://github.com/mAia-bird/threadloom).

## Обещание безопасности

Инструмент сделан для документов, которые нельзя потерять (налоги, документы,
договоры). Поэтому по устройству:

- **Никогда не удаляет.** Файлы *перемещаются* из входящих в архив (или
  *копируются*, если выберешь). Оригиналы Paperloom не трогает.
- **Никогда не перезаписывает.** При совпадении имени с другим содержимым
  добавляется ` (2)`.
- **Дедуп по содержимому, а не по имени.** Идентичный файл (та же контрольная
  сумма) откладывается в `_Duplicates/`, а не копится.
- **Сомневается — тихо спрашивает.** Файлы с низкой уверенностью уходят в
  `_Review/`, а не угадываются в неправильную папку.
- **`--dry-run` показывает весь план и ничего не меняет.** Всегда начинай с него.

## Возможности

- 📥 **Входящие → архив**, разложенный по *твоим* категориям (задаются в простом файле).
- 🧠 **Своя нейросеть** — локальная, по API или никакой. См. [ниже](#подключение-нейросети).
- ⚙️ **Слой правил** — правила по ключевым словам/именам раскладывают частые файлы
  мгновенно, бесплатно и офлайн, ещё до обращения к ИИ.
- 🖼️ **Картинки и сканы** — классифицируются vision-моделью, если подключишь.
- 🔁 **Режим слежения** — оставь запущенным, и новые файлы сортируются по приходу.
- 🔔 **Опциональное сообщение в Telegram** после каждого прогона.
- 🗂️ **Дружит с Google Drive** — см. [Google Drive](#использование-google-drive).

## Что нужно

- Python **3.9 или новее**. Больше ничего — никаких `pip install`.

## Быстрый старт

```bash
git clone https://github.com/mAia-bird/paperloom.git
cd paperloom
python run.py
```

Первый запуск поднимает мастер настройки. Потом закинь пару файлов во входящие и
**сначала всегда предпросмотр**:

```bash
python run.py --dry-run   # покажет, что будет, ничего не трогая
python run.py             # реально разложит
```

## Мастер настройки

`python run.py` (в первый раз) или `python run.py setup` проведёт через:

1. **Язык** — английский или русский.
2. **Папки** — пути входящих и архива, и *перемещать* или *копировать*.
3. **Категории** — начать с готового шаблона личных документов (Налоги, Банк,
   Страховки, Жильё, Документы, Договоры, Медицина, Счета, Архив) или с минимального.
   Правятся в любой момент в `config.json`.
4. **Нейросеть** — локальная / по API / Anthropic / никакой (следующий раздел).
5. **Уведомления** — опциональная сводка в Telegram.

Всё пишется в `config.json` (твои категории и папки — без секретов) и `.env`
(API-ключ, токен Telegram — в `.gitignore`).

## Подключение нейросети

Paperloom работает **вообще без ИИ** (правила по ключевым словам), но модель делает
его гораздо умнее — она реально *читает* документ. Подключить можно тремя
способами; выбирай по приватности и бюджету:

### 1. Локальная модель — максимально приватно, бесплатно

Модель работает **на твоём компьютере**, документы не покидают машину. Идеально для
налогов, документов, медицины.

- Поставь [**Ollama**](https://ollama.com) (или [LM Studio](https://lmstudio.ai)).
- Скачай модель, например `ollama pull llama3.1` (или vision-модель для сканов/фото:
  `ollama pull llava`).
- В мастере выбери **Локальная**; base URL `http://localhost:11434/v1`, без ключа,
  модель `llama3.1`.

### 2. По API-ключу — оплата за использование, точнее всего

Берёшь **API-ключ** у провайдера и платишь за использование (обычно доли копейки за
документ). Содержимое файла уходит этому провайдеру.

- [OpenAI](https://platform.openai.com) — base `https://api.openai.com/v1`, модель напр. `gpt-4o-mini`.
- [Anthropic](https://console.anthropic.com) — выбери в мастере **Anthropic**, модель напр. `claude-haiku-4-5`.
- [OpenRouter](https://openrouter.ai) — base `https://openrouter.ai/api/v1`, один ключ на **много** моделей (есть бесплатные).
- Любой другой OpenAI-совместимый эндпоинт (Together, Groq, …).

### 3. «Подписка» — прочти честно

Подписка **ChatGPT Plus** или **Claude Pro** — это для чат-приложений, она **не даёт
API-ключа** и для такого инструмента не подходит. Ближе всего к «по подписке» (один
более-менее фиксированный счёт, много моделей) — **OpenRouter** (по кредитам, есть
бесплатные модели). Иначе бери **локальную модель** (бесплатно) или **API-ключ с
оплатой за использование** выше.

> Если модель недоступна или вернула ерунду, Paperloom откатывается на правила по
> ключевым словам, а всё неясное отправляет в `_Review/` — на одном плохом файле он
> не падает.

### Чтение сканов и фото (vision)

Текстовые файлы и «цифровые» PDF читаются напрямую. У **сканов** PDF и картинок
(`.jpg`, `.png`) текста нет, поэтому нужна **мультимодальная** модель: выбери
vision-модель (например `gpt-4o-mini`, `claude-haiku-4-5` или локальную `llava`) и
ответь **да** на вопрос «модель мультимодальная?» в мастере. Без неё картинки
раскладываются по имени файла или уходят в `_Review/`.

## Как пользоваться

```bash
python run.py --dry-run       # безопасный предпросмотр — всегда начинай отсюда
python run.py                 # разобрать входящие один раз
python run.py --watch         # следить (добавь --interval 60 для 60с)
python run.py setup           # перезапустить мастер
```

По каждому файлу печатается строка: `📁 разложено`, `🔎 на разбор` или `♻️ дубль`,
затем однострочная сводка (при желании — в Telegram).

## Использование Google Drive

Хочешь, чтобы входящие и архив жили в Google Drive и были доступны со всех
устройств? Два пути.

### Простой, рекомендуемый: Google Drive для компьютера

[Google Drive для компьютера](https://www.google.com/drive/download/) монтирует
твой Drive как обычную папку. Тогда Paperloom **вообще не нужен доступ к аккаунту
Google** — он просто читает и пишет локальные пути:

1. Поставь Google Drive для компьютера и войди.
2. В мастере (или в `config.json`) укажи:
   - `inbox` на папку внутри примонтированного Drive, например
     `~/Library/CloudStorage/GoogleDrive-you@gmail.com/Мой диск/Входящие` (macOS) или
     `G:\Мой диск\Входящие` (Windows);
   - `archive` на другую папку в том же Drive.
3. Запускай `python run.py` как обычно. Разложенные файлы синхронизируются в Drive сами.

> **Важно:** некоторые системы запрещают *фоновым* процессам читать
> примонтированный Drive. Если фоновый/по расписанию запуск не видит папку —
> запускай Paperloom как обычный процесс на переднем плане (терминал или
> login-агент), а не как урезанный системный сервис.

Это прагматичный выбор, и он работает с **любым** облаком, у которого есть папка
десктоп-синхронизации (Dropbox, OneDrive, iCloud Drive) — Paperloom всё равно видит
только папки.

### Продвинутый: Google Drive API (не встроен)

Общаться с Drive напрямую через API (без монтирования) можно, но это тяжелее:
нужен проект в Google Cloud, согласие OAuth и — для чего-то, кроме твоего личного
аккаунта — верификация приложения у Google. Непроверенные приложения с широким
доступом к Drive получают экран *«приложение заблокировано»*, из-за чего такое
неудобно отдавать другим людям. Это в планах как опциональный бэкенд; пока
поддерживается путь с монтированием выше.

## Как файл попадает в категорию

1. **Сначала правила.** Если имя файла или его текст содержит ключевое слово,
   заданное для категории (`config.json` → `rules`), файл сразу раскладывается туда —
   бесплатно и мгновенно.
2. **Потом ИИ** (если включён) читает превью (или картинку) и выбирает категорию +
   аккуратное имя, с оценкой уверенности.
3. **Порог уверенности.** Ниже `min_confidence` (по умолчанию 0.6) или выдуманная
   моделью категория → `_Review/`.
4. **Проверка на дубль.** Тот же контент, что уже разложен → `_Duplicates/`.

## Справочник настроек

`config.json` (папки и категории — можно хранить) и `.env` (секреты — в
`.gitignore`). См. [`config.example.json`](config.example.json).

| Ключ `config.json` | Что это |
| --- | --- |
| `lang` | `en` или `ru`. |
| `inbox` / `archive` | Пути папок (`~` раскрывается). |
| `mode` | `move` (по умолчанию) или `copy` (оставлять оригиналы во входящих). |
| `min_confidence` | 0–1; ниже — догадка ИИ идёт в `_Review/`. |
| `duplicates_dir` / `review_dir` | Имена служебных папок. |
| `categories[]` | `{ name, description, rules: { filename_any[], text_any[] } }`. |
| `notify_telegram` | `true` — слать сводку в DM. |

| Ключ `.env` | Что это |
| --- | --- |
| `LLM_ENABLED` | `true` — использовать модель. |
| `LLM_PROVIDER` | `openai` (в т.ч. локально и OpenAI-совместимо) или `anthropic`. |
| `LLM_API_BASE` | напр. `http://localhost:11434/v1`, `https://api.openai.com/v1`. |
| `LLM_API_KEY` | API-ключ (пусто для локального сервера). |
| `LLM_MODEL` | напр. `llama3.1`, `gpt-4o-mini`, `claude-haiku-4-5`. |
| `LLM_VISION` | `true`, если модель умеет читать картинки/сканы. |
| `TELEGRAM_TOKEN` / `TELEGRAM_CHAT_ID` | Для опциональных уведомлений. |

## Приватность

С **локальной** моделью документы не покидают компьютер — Paperloom не делает
сетевых вызовов, кроме `localhost`. С **API**-моделью текст (или картинка) каждого
файла отправляется провайдеру для классификации; больше ничего не загружается, и
файлы никуда публично не выкладываются.

## Если что-то не так

- **Всё падает в `_Review/`.** Правила не сработали и ИИ не подключён (или
  недоступен). Добавь ключевые слова в категории или подключи модель.
- **Скан PDF не понят.** У сканов нет текстового слоя — подключи vision-модель и
  включи `LLM_VISION`.
- **«Не достучался до модели».** Для локальной — проверь, запущен ли Ollama/LM Studio
  и совпадает ли base URL/порт. Для API — проверь ключ и название модели.
- **Хочу откатить прогон.** Ничего не удалено — файлы в архиве (дубликаты в
  `_Duplicates/`). Перенеси их обратно во входящие и поправь правила.

## Как это устроено

Маленько и читаемо, всё на стандартной библиотеке:

| Файл | Роль |
| --- | --- |
| `paperloom/extract.py` | Best-effort текст-превью из файла (txt, pdf, …). |
| `paperloom/classify.py` | Правила + LLM → категория, имя, уверенность. |
| `paperloom/llm.py` | Клиент модели (локально / API / Anthropic, с vision). |
| `paperloom/organizer.py` | Дедуп по хэшу, безопасное move/copy, никогда не удаляет. |
| `paperloom/sorter.py` | Цикл разбора входящих. |
| `paperloom/setup_wizard.py` | Интерактивная настройка при первом запуске. |
